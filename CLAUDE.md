# S5 Glow Sticks

Цветной свет для сборки S5 (`s5glow`), Forge 1.20.1, Java 17. Отвечать по-русски.

Что делает: невидимые блоки цветного света `s5glow:colored_light_<цвет>` (15 цветов, уровень 0–15, как ванильный
`light`; уровень меняет ведущий правым кликом) и цветной свет светящихся палочек мода Glow Sticks — поставленных,
в руке, брошенных. Сам свет рисует FL Render (обязателен); мод только сообщает ему цвета.

Устройство (4 класса, пакет `faygolover.s5glow`):
- `S5Glow` — вход, регистрация блоков и предметов;
- `ColoredLightBlock` — блок цветного света;
- `GlowStickColors` — цвета палочек Glow Sticks; грузится, только если Glow Sticks стоит;
- `ClientHooks` — клиентская часть (отдельно, чтобы сервер не грузил клиентские классы).

Нельзя: менять id блоков `s5glow:colored_light_*` (они стоят в мире); трогать клиентские классы вне `ClientHooks`.
Заплатки самого мода Glow Sticks — в RP Fixes (`mixin/glowsticks`), не здесь.

Сборка: `gradlew.bat build`; проверка: `python ../_family/family.py verify "S5 Glow Sticks"`.
